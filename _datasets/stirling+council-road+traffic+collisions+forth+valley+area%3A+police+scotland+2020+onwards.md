notes: "<div style='color:#40566c; font-size:24px; line-height:1.25; margin:0 0 14px;'><strong>Description</strong></div>\n\
  <div style='color:#2f2f2f; font-size:16px; font-weight:400; line-height:1.5; word-break:normal;'><p\
  \ style='margin:0 0 24px;'>This Open Data dataset covers reportable road traffic\
  \ collisions recorded by Police Scotland within the Forth Valley area. It combines\
  \ collision records with their associated casualty records from Police Scotland\u2019\
  s Road Traffic Collision Dataset.</p><p style='margin:0 0 24px;'><a target='_blank'\
  \ href='https://www.scotland.police.uk/about-us/how-we-do-it/road-traffic-collision-data/'\
  \ rel='nofollow ugc noopener noreferrer'>View the source collision and casualty\
  \ data on the Police Scotland website</a>.</p><div style='color:#40566c; font-size:20px;\
  \ line-height:1.25; margin:0 0 12px;'><strong>Data status and updates</strong></div><p\
  \ style='margin:0 0 24px;'>Police Scotland publishes these records as provisional\
  \ management information. They are not official statistics and should not be compared\
  \ directly with official statistics.</p><p style='margin:0 0 24px;'>Police Scotland\
  \ publishes the source data quarterly, using snapshots taken on 2 January, 2 April,\
  \ 2 July and 2 October. Earlier records are refreshed to reflect the latest information\
  \ held, so figures for previous periods may change.</p><div style='color:#40566c;\
  \ font-size:20px; line-height:1.25; margin:0 0 12px;'><strong>How the data is recorded</strong></div><p\
  \ style='margin:0 0 24px;'>Police Scotland adopted the Collision Recording and Sharing\
  \ system (CRaSH) in 2019. Before CRaSH, Police Scotland compiled STATS19 data from\
  \ several legacy systems. Differences in data structures and recording practices\
  \ mean that earlier records are less consistent.</p><p style='margin:0 0 24px;'>The\
  \ STATS19 data collection form sets out what information is recorded about reported\
  \ road traffic collisions. The STATS20 manual provides guidance on completing collision\
  \ reports from sources other than CRaSH.</p><div style='color:#40566c; font-size:20px;\
  \ line-height:1.25; margin:0 0 12px;'><strong>Comparing figures over time</strong></div><p\
  \ style='margin:0 0 24px;'>COVID-19 restrictions and lockdowns affected travel during\
  \ 2020/21. Police Scotland recommends using a five-year average as a baseline for\
  \ comparison, or a three-year average where five years of data are unavailable.\
  \ Take care when interpreting comparisons between 2020/21 and 2019/20.</p><p style='margin:0;'>Transport\
  \ Scotland and the Department for Transport publish official statistics on road\
  \ traffic collisions and casualties. The Department for Transport also publishes\
  \ historical collision statistics for periods before 2020.</p></div>"
